Скрипты — `scripts/instagram/`:
- `new-post.py` — одна картинка любого вида (`python3 new-post.py -h`);
- `new-carousel.py` — карусели из `carousels.tsv` (строка = слайд);
- `render-all.py` — весь набор из `set.json` + `carousels.tsv`;
- данные сайта (имена, роли, оффер, примеры общения) — `site.js`;
- фото-подложки `plate-<id>.jpg` (натюрморт из интерьера эксперта) и `plate-pin-L|C|R.jpg` (триптих закрепов; R — зеркало L), `plate-pin-offer.jpg` (сторис-оффер, «Начать») — для цитат, закрепов, слайдов 2–7, сторис-оффера/цитаты и «Актуального». Новый эксперт = новая подложка 1080×1440 с пустой верхней половиной (свет, тени окна, предметы внизу) + строка в `PPOS`/`HPOS` в `ig.html`.

Все печатают OK/BAD; с BAD не публиковать — сократите текст.

## Безопасные зоны

- **Посты 1080×1350.** Сетка профиля показывает 3:4 — центр 1012×1350. Весь текст — в x 100–980.
- **Сторис и Reels 1080×1920.** Свободно сверху 269 px (14%), снизу 672 px (35%), по бокам 65 px. Текст сторис — в y 300–1014, Reels — в y 300–864. Стикер — в пунктирной зоне.
- **«Актуальное».** Значок в центральном круге ∅760.

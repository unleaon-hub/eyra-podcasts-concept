# EYRA · Instagram — пробный набор

Главная картинка: `instagram-overview.png`. Макет профиля: `previews/mock-profile.png`. Тексты, порядок публикации и подписи: `TEXTS.md`.

| Папка / файл | Что это | Куда |
|---|---|---|
| `profile/avatar-800.png` | Аватар-полосы (как на всех площадках) | Профиль → Редактировать → Изменить фото |
| `grid/01…09-*-1080x1350.jpg` | 9 постов 4:5, цвета экспертов идут радугой как на аватаре | Лента. Публиковать с 09 по 01: новый пост встаёт слева сверху (см. `TEXTS.md`) |
| `carousel/maya-1…6-of-6-1080x1350.jpg` | Карусель Майи «Как восстановиться за выходной», 6 слайдов | Один пост, «Выбрать несколько», порядок 1–6. Слайд 1 — тот же, что `grid/08` |
| `stories/*-1080x1920.jpg` | 4 шаблона сторис: вопрос дня, опрос, цитата, новый выпуск | Сторис. Стикер «Вопросы», «Опрос» или «Ссылка» ставится в приложении в оставленное место (`previews/stories-guides/`) |
| `highlights/<id>-highlight-1080x1920.jpg` | 10 обложек «Актуального» | Актуальное → Редактировать → Изменить обложку → выбрать картинку, круг по центру |
| `reels/covers/<id>-reels-cover-1080x1920.jpg` | Обложки Reels | При публикации Reels → Обложка → Добавить из галереи |
| `reels/frames/<id>.png` (+ `.layout`) | Кадр для видео-тизера: место под волну и прогресс | `FRAME=instagram/reels/frames/<id>.png ./scripts/make-vertical-teaser.sh <аудио> <id>` |
| `previews/` | Макет профиля, ряд кругов «Актуального», сторис и Reels с безопасными зонами | Не загружать |

Новые картинки — `scripts/instagram/new-post.py` (все виды, справка: `python3 new-post.py -h`); весь набор заново — `scripts/instagram/render-all.py` (список в `scripts/instagram/set.json`).

## Требования Instagram (проверено 19.11.2026)

| Что | Требование | Источник |
|---|---|---|
| Фото в ленте | Ширина до 1080 px; от 1.91:1 до 3:4 (1080×566 … 1080×1440) сохраняется без обрезки; другое соотношение обрежется | Instagram Help: https://help.instagram.com/1631821640426723 (официально) |
| Карусель | До 20 фото и видео; одна ориентация на все слайды; в профиле видна первая | https://help.instagram.com/269314186824048 (официально) |
| Сетка профиля | Плитки вытянутые 3:4 (с января 2025); пост 4:5 теряет ~34 px с каждого бока (видно 1012×1350) | В справке соотношения нет. Смена сетки — Адам Моссери, январь 2025 (The Verge); 3:4 — по гайдам Kapwing, Planoly |
| Почему 4:5, а не 3:4 | 4:5 (1080×1350) принимают и приложение, и планировщики/реклама через API Meta (там максимум 4:5) | Сторонние гайды (superprofile.bio, wavegrain.com); 3:4 можно, если публиковать только из приложения |
| Reels / сторис | 9:16; Meta советует оставлять свободными сверху 14%, снизу 35%, по бокам 6% (на 1080×1920: 269 / 672 / 65 px); для рекламы — 1440×2560 | Meta Ads Guide, Instagram Reels: https://www.facebook.com/business/ads-guide/update/video/instagram-reels (официально, для рекламы; интерфейс тот же) |
| Обложка Reels в сетке | Обрезается до 3:4 по центру (на 1080×1920 видно y 240–1680) | Наблюдение и сторонние гайды |
| Фото профиля | Размер в справке не указан; круг; на практике ≥320×320 | Справка: https://help.instagram.com/557544397610546; 320×320 — сторонние гайды |
| Обложка «Актуального» | Официального размера нет: картинка 9:16, в профиле — круг из центра | Наблюдение |
| Описание профиля | 150 символов | Сторонние гайды (в справке не нашёл) |

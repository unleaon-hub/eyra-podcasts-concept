# EYRA · Threads — тот же стиль, что Instagram v5

Светлые сцены экспертов, фото-натюрморты под матовыми карточками, крупные аватары с белой обводкой, логотип EYRA, шрифт Manrope. Шаблон общий с Instagram (`scripts/instagram/ig.html`). Цель та же: привести человека к эксперту в Telegram. Оффер «7 дней бесплатно · Без банковской карты» — дословно с eyra.ink.

Начните с макета: `previews/threads-profile-mock.png` (профиль и лента на телефоне, 390 px) и `previews/threads-thread-mock-asya.png` (тред целиком). Все картинки на одном листе: `previews/threads-overview.png`.

## Что где лежит

| Файл | Размер | Куда в Threads | Новое или взято из Instagram |
|---|---|---|---|
| `profile/avatar-800.png` | 800×800 | **Редактировать профиль → фото**, или **«Импорт из Instagram»** | тот же файл, что в `instagram/profile/` |
| `../instagram/pinned/1…3-*-1080x1350.jpg` | 1080×1350 | Один пост-карусель из трёх закрепов → ⋯ → **«Закрепить в профиле»**. Текст — `THREADS.md`, п. 2 | из Instagram (не копируем) |
| `posts/<id>-post-1080x1350.jpg` | 1080×1350, 4:5 | Первый пост треда эксперта: сцена + вопрос, «4 совета от … — в ветке ниже» | новое (10) |
| `quotes/<id>-quote-1080x1350.jpg` | 1080×1350 | Отдельный пост-цитата | новое (10; у Ники, Веры, Софии, Леры цитаты те же, что в Instagram) |
| `../instagram/carousel/<id>/…-1…7-of-7-1080x1350.jpg` | 1080×1350 | Пост-карусель (по желанию), 7 фото | из Instagram (не копируем) |
| `link-preview/og-home-1200x630.jpg`, `og-<id>-1200x630.jpg` | 1200×630 | **Не загружается в Threads.** Предложение для `og:image` на сайте: Threads берёт превью ссылки со страницы | новое (11) |
| `THREADS.md` | | Описание профиля, закреп, 10 тредов (хук + 4 ответа + финал), карусели, цитаты, опросы, порядок | новое, **черновик** |
| `threads-texts.tsv`, `threads-texts.js` | | Те же тексты таблицей (с длиной) и для макета | генерируются |

Сейчас сайт отдаёт свои og-картинки: на главной `eyra-share-cover-v2…png` 1914×822, на страницах экспертов `<id>-og…jpg` 1200×630, обе тёмные. Наши светлые карточки — только предложение. Менять их нужно на сайте, в `<meta property="og:image">`, потом проверить превью в Threads или Facebook Sharing Debugger.

## Требования Threads (проверено 19.11.2026)

| Что | Значение | Источник |
|---|---|---|
| Фото | JPEG или PNG, до 8 МБ, ширина не меньше 320 px (меньше растягивается), больше 4096×4096 уменьшается, соотношение сторон до 10:1, sRGB | официально: https://developers.facebook.com/docs/threads/overview |
| Как фото показывается в ленте | одиночное фото почти без обрезки; 4:5 — рекомендуемый формат; очень высокие фото в превью ленты обрезаются примерно до 4:5 | сторонние гайды (socialk.it, postfa.st); Meta не публикует |
| Карусель | от 2 до 20 фото или видео (API). По сторонним гайдам, в приложении до 10 | официально: overview; про 10 — postfa.st |
| Карусель в ленте | кадры одной высоты, следующий выглядывает справа; до 3:4 без обрезки; углы скруглены, важное держать на 5% от края | сторонние гайды (seriesphotos, socialk.it) |
| Видео | MOV или MP4, H.264 или HEVC, звук AAC до 48 кГц, 23–60 кадров/с, ширина до 1920 px, до 5 минут и 1 ГБ; рекомендовано 9:16 | официально: overview |
| Текст поста | до 500 символов; эмодзи считаются по байтам UTF-8 | официально: overview (500) и https://developers.facebook.com/docs/threads/posts (эмодзи) |
| Ссылки | до 5 в посте (с 22.12.2025 больше 5 — ошибка); первая ссылка в тексте становится превью. Если в посте есть фото или видео, карточки превью обычно нет (по наблюдению), поэтому ссылку ставим в финальный ответ без фото | официально: https://developers.facebook.com/docs/threads/posts и https://developers.facebook.com/docs/threads/create-posts/text-attachments |
| Тема (topic) | одна на пост, 1–50 символов, без точек и «&» | официально: https://developers.facebook.com/docs/threads/posts |
| Опрос | 2–4 варианта, по 1–25 символов; идёт 24 часа | официально (варианты): https://developers.facebook.com/docs/threads/create-posts/polls; 24 часа — по сторонним гайдам |
| Вложение-текст | до 10 000 символов и 1 ссылка, только в текстовом посте, без опроса | официально: text-attachments |
| Закреп | в профиле можно закрепить **1** пост (⋯ → «Закрепить в профиле»); в своей ветке можно закрепить ответ | официально: https://help.instagram.com/323726840378106 |
| Профиль | имя, имя пользователя, описание, ссылки, фото; фото и данные можно импортировать из Instagram; обложки (баннера) нет | официально: https://www.facebook.com/help/instagram/759628745637994; импорт — trypostbase; без баннера — по наблюдению |
| Ссылки в профиле | до 5 | Meta, май 2025, в пересказе (writepadpro) |
| Описание профиля | 150 символов | только сторонние справочники |
| Размер фото профиля | Meta не указывает. Берём тот же квадрат 800×800, что в Instagram | — |
| Превью ссылки | отдельного размера для Threads Meta не даёт; 1200×630 (1.91:1) — общая рекомендация Open Graph для Facebook | сторонние: linkcard, mediasizes |
| Правка текста | 15 минут после публикации | Справочный центр, в пересказе (postnext) |

## Как пересобрать

```bash
cd scripts/threads
python3 render-threads.py            # posts/ + quotes/ + link-preview/ -> ../../threads/ (печатает OK/BAD)
python3 render-threads.py og         # только og-карточки (фоны bg-og-*.jpg делает ../instagram/mk-og.py)
python3 mktexts.py                   # THREADS.md + threads-texts.tsv/.js; код 1, если пост > 500 символов
python3 shot-mock.py asya sofia      # макеты профиля и тредов в previews/
```
Тексты меняйте в `threads.json` (цитаты, темы, опросы, описание), советы — в `../instagram/carousels.tsv`, формулировки сайта — в `../instagram/site.js`. С `BAD` или с превышением лимита не публиковать — сократить текст. Нужны Python 3, Playwright и Chrome (как для Instagram).

**Безопасные зоны**
- **Основная обложка 1920×768.** На телефоне края обрезаются; справка VK советует держать важное в 10–15% от краёв, это 192–288 px по бокам. Логотип и ряд экспертов стоят в x 402–1518 и y 202–530, то есть внутри центра 1196×400, видимого на телефоне. Поля по бокам 21%. Нижний левый угол свободен под аватар: на компьютере примерно x 0–330, на телефоне x 362–640, по высоте y ≥ 600.
- **Живая обложка 1080×1920.** Верх 0–280 px занят статус-баром и кнопками «назад»/«меню», низ 1520–1920 px — названием сообщества и кнопками «Подписаться» и «Написать». Там только фон: стена сверху, низ кадра снизу. Логотип стоит на y 300–475, лица — примерно на y 560–1120. Рекламных надписей нет.

**Пересборка** (обычно не нужна): основная обложка — `scripts/banner/ch4.html?m=vk` в Chromium, окно 1920×768. Слайды живой обложки: `cd scripts/vk && python3 lock.py 120 && python3 live.py` → `slide-<id>.png`, видео: `python3 kb.py` → `live-cover.mp4` (нужны Pillow, numpy, Playwright с Chromium и ffmpeg; около 2 минут).

## Дзен

Все файлы для Дзена лежат в `dzen/`. Готовые файлы из других папок тоже подходят, см. таблицу.

**Что есть в Дзене (по Справке, ноябрь 2026).** Форматы: статьи, посты, горизонтальные видео и вертикальные Ролики. Отдельного формата для аудио и подкастов в Справке нет. Поэтому выпуск подкаста публикуется как видео: кадр эксперта с живой волной (`make-episode-video.sh`) или тизер-Ролик (`make-vertical-teaser.sh`). Ссылки на сам подкаст (Яндекс Музыка, Apple Podcasts и др.) ставятся в «Настройки → Дополнительно → Соцсети», не больше 5 ссылок.

**Безопасные зоны**
- **Обложка канала.** Шаблон Дзена с разметкой в Справке не опубликован. Поэтому на обеих версиях логотип и ряд экспертов стоят по центру. На версии для компьютера блок занимает y 64–436 из 500 и x 759–2241 из 3000, поля по бокам 25%. На версии для телефона: y 255–645 из 1080, x 288–1632, низ (~40%) свободен под аватар и имя.
- **Ролик 1080×1920.** Верх 0–170 px — шапка; справа примерно x 900–1080 и y 1000–1640 — кнопки (лайк, комментарии, поделиться); низ 1640–1920 — канал, «Подписаться» и описание. Логотип стоит на y 186–307. Имя и название — между логотипом и головой эксперта. Головы всех экспертов начинаются на y ≈ 800, лица — примерно на y 850–1100. Если ленту обрезать до 3:4 по центру (y 240–1680), название останется целиком.
- **Обложка видео 1920×1080.** Текст только слева, правый нижний угол свободен под длительность.

**Тизер для Ролика из аудио выпуска**
```bash
cd scripts
START=754 LEN=45 ./make-vertical-teaser.sh ~/audio/ep12.wav asya ep12-asya-teaser.mp4      # отрезок 12:34–13:19
python3 new-cover.py asya "Почему трудно отпустить" --kind vertical-frame                  # кадр с названием тизера + .layout рядом
FRAME=asya-pochemu-trudno-otpustit-vertical-frame-1080x1920.png START=754 LEN=45 ./make-vertical-teaser.sh ep12.wav asya
python3 new-cover.py asya "Почему трудно отпустить" --kind vertical                        # обложка Ролика 1080×1920
```
- `START` — с какой секунды брать отрезок, `LEN` — длина (по умолчанию 60 с; скрипт не даёт меньше 5 и больше 120 с).
- Громкость выравнивается до −14 LUFS (Дзен просит тише −12 LUFS), в начале и в конце мягкие затухания. `LOUD=0` выключает выравнивание.
- На выходе MP4 1080×1920, H.264 High, 30 к/с, AAC 48 кГц стерео 192 кбит/с, faststart.
- `new-cover.py --kind vertical-frame` кладёт рядом с кадром файл `.layout`: так волна встаёт ровно под название любой длины. Так же работает `--kind frame` для горизонтального `make-episode-video.sh`.

## Видео для нового выпуска (ffmpeg)

```bash
cd scripts
./make-episode-video.sh ~/audio/ep12.wav asya ep12-asya.mp4
```

Скрипт берёт кадр эксперта и добавляет живую волну по звуку и тонкую линию прогресса, цвет — акцент эксперта.
Волна стоит в левой колонке, выше панели управления плеера.
На выходе MP4 1920×1080: H.264 High, yuv420p, 30 к/с, AAC 48 кГц стерео 256 кбит/с, faststart. Подходит и для YouTube, и для RUTUBE.
Скорость: примерно 3× реального времени, то есть час аудио кодируется около 20 минут.
Опции: `PRESET=fast` — быстрее, `CRF=18` — качественнее, `FRAME=свой-кадр.png` — кадр с названием выпуска (см. ниже).
Нужен ffmpeg 5 или новее (`brew install ffmpeg` / `apt install ffmpeg`).

## Обложка нового выпуска (шаблон)

```bash
pip install playwright pillow && playwright install chromium   # один раз
cd scripts
python3 new-cover.py vera "Луна в Раке: что важно знать"          # обложка 1920×1080 JPG
python3 new-cover.py kira "Сахар и усталость" --kind frame         # кадр для видео с названием
FRAME=kira-sahar-i-ustalost-frame-1920x1080.png ./make-episode-video.sh ep13.wav kira
```

Название — 2–3 строки, лучше до ~32 знаков.
Скрипт сам проверяет, что текст не заходит на эксперта и помещается в колонку; если нет, предупредит.
Шаблон лежит в `scripts/template/` (HTML, данные экспертов, фоны и маски).
Исходник баннеров — в `scripts/banner/` (`ch4.html`, `lock.js`, `tiles.py`). Исходник аватара — `scripts/avatar/badge.html`, сборка: `cd scripts/avatar && python3 render.py` → `avatar-800.png`.

## Правила
- Логотип латиницей «EYRA», в русском тексте — «Эйра».
- Текст никогда не ставим на лицо.
- Нижние углы превью на RUTUBE не заняты: там значок 12+ и длительность.
- В кит не входят старые тёмные баннеры A/B и вариант B светлого баннера: они не утверждены.

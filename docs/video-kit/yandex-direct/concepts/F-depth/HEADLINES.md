# Банк заголовков · по 5 на эксперта (ЧЕРНОВИК)

Эти заголовки станут 5 креативами каждого эксперта в финальной партии. Лучший заход отмечен ★, он стоит на креативах концепта F.

**Правила:**
- две строки, в строке до 11–12 знаков (при кегле 136 px помещается около 11; если длиннее, шаблон уменьшает кегль);
- короткие слова и конкретная боль или желание, своими словами клиента;
- вопрос, если он про его ситуацию;
- никаких цифр, сроков и гарантий результата.

**Ограничения модерации:**
- питание: «похудеть» без «на N кг» и «за N дней»;
- психолог: без «лечения», «терапии» и диагнозов;
- финансы: без обещаний дохода и без слова «кредит» в заголовке (оно включает категорию финуслуг);
- Таро, астрология и нумерология: вопрос или приглашение, без «точно» и «гарантированно».

| Эксперт | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **Кира** · нутрициолог | ★ Похудеть / без диет | Худеть / без голода | Хватит / срываться | Есть вкусно / и худеть | Меню / на неделю |
| **Ася** · психолог | ★ Не с кем / поговорить? | Тревожно? / Поговорим | Устали / от всего? | Опять / не спится? | Когда / накрывает |
| **Ева** · нетворкинг | ★ Знакомства / для дела | Нужные / знакомства | Боитесь / написать? | Напишите / первым | Найти / партнёра |
| **София** · финансы | ★ Куда уходят / деньги? | Не хватает / до зарплаты? | Свой план / накоплений | Отложить / с зарплаты | Ипотека / без паники |
| **Мира** · нумеролог | ★ Что скажут / ваши числа? | Обсудим / ваши планы | Ваш год / по числам | Число / вашей судьбы | Ваша дата / рождения |
| **Лера** · таролог | ★ Уйти / или остаться? | Он / вернётся? | Расклад / на любовь | Что ждёт / в отношениях? | Карта дня / для вас |
| **Вера** · астролог | ★ Что говорят / звёзды? | Ретроград? / Разберём | Совместимость / по дате | Натальная / карта | Ваш месяц / по звёздам |
| **Ника** · продюсер | ★ Вас не видят / клиенты? | Стать / заметнее | Личный бренд / с нуля | О чём / писать в блог? | Упаковать / экспертность |
| **Майя** · лайфстайл | ★ Скучно / в выходные? | Куда пойти / вечером? | Дни / одинаковые? | Идеи / на выходные | Свидание / без шаблона |
| **Алиса** · дейтинг | ★ Что ему / ответить? | Не пишут / первыми? | Первое / сообщение | Анкета, / которая цепляет | Свидание / без неловкости |

**Почему эти ★:**
- **Кира.** «Похудеть» — главный запрос в теме, «без диет» снимает главный страх. Это прямо из описания эксперта: «питание в вашем ритме».
- **Ася.** «Не с кем поговорить?» — это боль одиночества и усталости своими словами. Продукт отвечает на неё прямо: собеседник есть, в Telegram.
- **Ева.** «Знакомства для дела» сразу объясняет, что это за эксперт. Слово «нетворкинг» для широкой аудитории холоднее.
- **София.** «Куда уходят деньги?» — самый частый вопрос о личных финансах, без обещания дохода.
- **Мира.** Вопрос вызывает любопытство и говорит о личном: «ваши» числа.
- **Лера.** Выбор в отношениях — главный повод для расклада, и это прямо из описания: «когда перед вами выбор».
- **Вера.** Классический вход в тему.
- **Ника.** Боль эксперта, которого не замечают.
- **Майя.** Скука как триггер.
- **Алиса.** Самая частая ситуация в переписке.

**Длина:**
- Если строка длиннее 11 знаков («поговорить?», «Куда уходят», «ваши числа?»), шаблон уменьшает кегль на 4–6%.
- Самые длинные варианты («Не хватает / до зарплаты?», «Совместимость», «Что ждёт / в отношениях?», «Анкета, / которая цепляет», «Свидание / без неловкости») уменьшатся сильнее, примерно на 10–15%. Их лучше проверить при сборке партии.

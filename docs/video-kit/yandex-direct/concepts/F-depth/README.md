# Концепт F «Глубина» (ЧЕРНОВИК)

Вёрстка взята из E2: имя «Имя.», тонкий крупный заголовок, роль, тёмная плашка «7 дней бесплатно», маленький знак EYRA и строка «Без банковской карты». Что изменилось по сравнению с E:

1. **Сцена в две зоны, как у эталона.** Слева примерно 40–46% кадра — светлая тонированная стена с оконным светом, на ней текст. Справа, за экспертом, глубокая тёмная стена, у каждого эксперта своя, с абстрактной картиной, растением и тематическим предметом:

| Эксперт | Стена за экспертом | Предмет |
|---|---|---|
| Мира | бутылочно-зелёная | часы |
| Кира | лесная олива | фрукты на полке |
| Ася | эспрессо-терракота | чайник с чашкой |
| Ева | тёмный индиго | визитки и лампа |
| София | глубокий тил | копилка |

   Сцены — правка сцен кита (кадр и эксперт те же). Лица сверены в `previews/F-faces.jpg`.

2. **Буквы меняют цвет на границе, как в эталоне.** У эталона вторая строка заголовка заходит на тёмную стену. Буквы там белые (#fff на rgb(41,48,51)), граница проходит ровно по краю стены, прямо посреди буквы: в «плаНЫ» у «н» левая половина чёрная, правая белая. В F заголовок рисуется дважды: тёмным везде и белым по маске тёмного фона. Маска строится по реальным пикселям сцены (яркость < 92 после размытия 7 px), поэтому граница повторяет край стены. Если строка заходит на тёмные волосы или одежду, буквы там тоже белеют. Кадр подбирается так, чтобы хвост заголовка заходил за край стены на 50–110 px и не доходил до волос и лица ближе чем на 50 px.

3. **Сильные заголовки.** Полный банк, по 5 на каждого из 10 экспертов, лежит в `HEADLINES.md`. На креативах стоят лучшие заходы:
   - Кира — «Похудеть / без диет»;
   - Ася — «Не с кем / поговорить?»;
   - Ева — «Знакомства / для дела»;
   - Мира — «Что скажут / ваши числа?»;
   - София — «Куда уходят / деньги?».

**Пересборка** (из `scripts/yandex-direct/`):
1. `mk-scenes-f.py <id>`: увеличение сцены и маска (запускать из rembg-venv, по одному эксперту).
2. `mk-bg-f.py`: осветляет левую стену до уровня эталона и пишет `scenes-f/geo.js`.
3. `render-f.py`.
4. `sheets-f.py`.

Шаблон: `depth.html?e=<id>[&h=строка1|строка2]`.
